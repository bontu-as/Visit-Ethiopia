# Visit Ethiopia 🇪🇹

A tourism website designed to showcase Ethiopia's beautiful destinations, rich cultural heritage, historical landmarks, and natural attractions.

## About the Project

Visit Ethiopia is a web development project that aims to introduce visitors to Ethiopia's tourism opportunities. It provides an engaging way to explore the country's destinations and discover its cultural and historical attractions.

## Features

- Explore popular tourist destinations in Ethiopia.
- Discover historical and cultural attractions.
- View information about different places.
- Responsive and user-friendly website design.
- Simple navigation between website sections.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout

## Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `html/index.html` in your web browser.

## Project Purpose

This project was developed to practice front-end web development skills, improve HTML and CSS knowledge, and create a website that highlights Ethiopia's tourism potential.
